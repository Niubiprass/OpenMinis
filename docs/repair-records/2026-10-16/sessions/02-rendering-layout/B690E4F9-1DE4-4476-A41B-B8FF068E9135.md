外部研究对当前补丁的复核结论：
1. 双入口已统一，不再保留 raw 与 high-water 两种公开拟合语义。
2. 同宽持久 max 已改为有可信释放条件的暂存保护；零/近零/非有限值仍回退最后实际接受值，不提升候选低值为 fallback。
3. 收缩确认后逐层失效 cell/seed、layout/precalc、render-qualified memo，避免宿主已改正而上层仍返回旧高。
4. `super` fitting ceiling 已删除，保留 compressed input 与 TextKit floor；无 TextKit 的 tool/thinking 不再因缺乏所谓 TK 增长授权而被限高。
5. anchor 在测量纠正前捕获，以 item 身份恢复屏幕相对位置，不用历史最大高度保护位置。
6. Apple containment 缺口仍需独立 A/B 核验；本次未混改。simonbs 来源准确记录为 gist：`https://gist.github.com/simonbs/457725e218fc85fc765ed770815314df`。
7. 同 revision 固定宽的 **raw 是否受父 bounds 影响而稳定错误**尚无实际运行试验证据；这是后续必须证伪的第一步，不应把模型测试通过当成此项已确认。
