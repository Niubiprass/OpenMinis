### 1. 修复 `deferredHeights` 按 index 错写

文件：`src/ios/Agent/MessageList/MessageListLayout.swift`

- `updateCacheForSnapshot(oldIds:newIds:)` 现在使用 `MessageListItem` 身份映射 `deferredHeights`：
  - 旧 item A 重排到新 index 时，高度跟随 A；
  - 删除的 item 不会把高度写给新 item；
  - prepend、reorder、append 都不会再按旧 index 直接复用延迟高度。
- `clearHeightCache()` 现在同时清空 `deferredHeights`，避免会话切换、字体/宽度重置后把旧会话高度带入新快照。
- `invalidateHeight(at:)`、`setCachedHeight(_:)` 和 preferred-layout 高度已经接受的路径都会取消同 index 的旧延迟值。
- 因此快滑期间：
  - A 暂存的小幅收缩；
  - 随后 A 或新 item 接受了更新的测量；
