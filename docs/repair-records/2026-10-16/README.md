# 分类修复资料快照

入口：[清理前总记录](../../OPENMINIS-ALL-REPAIR-RECORDS-2026-10-16.md)。

- sessions/: 相关主会话和子任务纯文本，按主题分类，已做凭据/邮箱/电话脱敏。
- source-docs/、older-worktree-docs/: 现存修复文档快照，旧判断保留但不覆盖最新更正。
- PROJECT-MEMORY.md: 项目相关每日记忆。
- GIT-HISTORY.md / ci-history/: 历史索引，不表示所有版本实机通过。
- unsubmitted-drafts/: 未提交/未执行草稿，不等同于修复完成。
- LOCAL-EVIDENCE-MANIFEST.json: 本地证据文件校验清单；原始截图/视频/设备日志未公开上传。
- SHA256SUMS: 本目录文件及总记录的校验值（不含自己）。

这是人工可读的交接备份，不是App数据库导入包；凭据、设置与附件需单独保管。
