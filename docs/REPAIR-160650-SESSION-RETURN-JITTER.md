## 证据边界与纠正
- `tkFound=1`是Bool，并非TextView数量；不能由此证明只有一个或一定重复。
- `cached=true`是MessageListLayout的heightCache存在，不代表SelfSizingCell哪个短路被命中。
- 可以确认同item持续748/1215竞争，且无须新正文批次或拖动；不能断言全部由requestScroll、120ms收缩定时器或网络造成。
- 源码确定缺口：两次hosting测量前的子树数组是生命周期保活快照，却在测量后被无归属地累加lastComputedHeight。到底是旧视图、重叠视图还是单个旧高度，旧诊断不能二选一。

## 本次候选修复
生产改动仅两个文件：
1. `MessageListInfrastructure.swift`：iOS15保活数组仅用于原有保活；在两次测量后重新遍历当前contentView。排除脱离当前窗口/当前cell、隐藏、透明、滚动文档、嵌套已计入父文本的视图。读取有当前渲染指纹的高度；真实垂直分段可以相加，重叠视图集合有歧义则放弃外层floor，保留宿主结果，不简单取max伪装去重。
2. `SelectableMarkdownView.swift`：新增只读高度访问器，iOS15必须匹配当前文本长度、hash、渲染宽和闩锁宽，才返回当前ios15LatchedNeedH；不把旧lastComputedHeight当新测量，不在外层递归测TextKit。
- iOS16+保持原合并路径；不增加永久历史最大值锁，不修改合法收缩/增长、宿主生命周期或偏好默认值。
- CONVERGE增加实际候选数量和拒绝数量字段，避免继续误读Bool。
