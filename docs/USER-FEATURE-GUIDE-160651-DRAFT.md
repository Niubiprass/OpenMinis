## 本轮同时修复：默认模型分组选择后无法保存

- **修复什么**：iOS15.5上多选模型后，顶部只有“取消”，看不到真正提交的“添加（数量）”。这不是点选没成功，而是提交按钮被工具栏结构隐藏。
- **有什么用**：将取消与添加拆成独立工具栏项，恢复明确的提交入口；保留选择计数、空选择禁用和现有保存回调。点击取消仍不保存。
- **使用场景**：设置默认主模型组、默认副模型组，从模型创建新组，或向已有模型组添加成员。共用多选选择器的入口一起受益，不自动替换你当前默认模型。
- **怎么使用**：设置→模型分组（或默认组槽位）→添加模型/从模型新建组→勾选模型→右上角“添加（N）”。重新打开检查成员仍在；取消应不改变成员。
- **状态与来源**：`UnifiedModelPicker.toolbarContent`逐字复用GitHub本仓库历史提交`255a24feac02ab02ab24535bceee3207d0204112`（iOS15兼容实现），取消与添加各自独立。4项源码检查通过，真实iOS15.5 SwiftUI编译因无Xcode未执行，尚未安装验证。没有把新候选说成手机上已修好。

## 一、本轮确认加入的分组功能

### 1. 首页会话分组专属设置
- **作用**：按首页会话文件夹的稳定ID保存技能、灵魂和记忆策略。同名或改名不影响归属，不与“模型分组”混用。
- **场景**：建立“iOS开发”“日常生活”“写作”等分组，让不同用途拥有不同默认配置。
- **状态**：已确认需求，尚未完整实现。

### 2. 分组默认技能＋会话覆盖
- **作用**：配置这个组默认可用的技能；单个会话仍可覆盖。优先级为会话覆盖 > 分组默认 > 应用默认，区分继承、全部关闭和指定技能。
- **场景**：“开发”组默认启用编程技能，“写作”组只启用写作技能；组里某个特殊会话再临时调整。
- **边界**：列入提示的技能目录不是恶意代码执行沙箱；新安装技能是否进入指定集合不能被隐式改变。
- **状态**：已确认需求，待接通实际解析链。

### 3. 分组灵魂提示词
- **作用**：不同分组使用不同角色、答复风格和工作约定，并真正进入模型请求；会话可显式覆盖，恢复继承不等于清空。
- **场景**：“开发”组要求直接给代码和验证步骤，“生活”组使用更自然的交流风格。
- **状态**：已确认需求，待接通请求构建链；不会仅保存设置却继续发送旧提示词。

### 4. 分组独立记忆
- **作用**：开启后，同组会话共享本组记忆，新增记忆只写本组。未启用的组和旧会话保留当前全局行为。
- **场景**：在某开发会话记下工程约定，同组另一个会话能继续使用；其他独立组不自动召回它。
- **边界**：不迁移、复制、删除现有全局记忆；不能撤销旧消息或模型已读到的信息。共享rootfs中的逻辑隔离不宣传成防恶意代码的安全沙箱。
- **状态**：已确认需求，执行/文件/URL/子代理/定时入口一致接通并验证前不开放开关。

### 5. “读取全局记忆（只读）”开关
- **作用**：独立组默认关闭；手动打开后可读取已有全局记忆，但组内新增记忆仍只写本组。
- **场景**：开发组希望继续知道你的通用偏好，又不把项目细节写回全局。
- **边界**：组内看到的全局内容只读，修改必须明确进入全局记忆管理；关闭开关不等于抹除历史聊天里已经出现的内容。
- **状态**：用户已批准设计，待运行时完整接线。

## 二、记忆不只有自动读写：管理功能

| 功能 | 作用 | 使用场景 | 实际状态 |
|---|---|---|---|
| 查看记忆与来源 | 查看全文，并在分组场景区分本组、全局来源 | 查清AI记住了什么 | 现有会话记忆页保留；新增组来源/只读标注未接入 |
| 搜索记忆 | 按文件名、正文和来源标题过滤 | 找工程规则或旧结论 | 新草稿已停用；FileBrowser现成搜索仅覆盖文件名，正文搜索未落实 |
| 编辑记忆 | 手动修正已保存的正文 | 修正项目名称、版本号、失效结论 | 使用160650原有MemoryFileEditView/MemoryContentView；未新增组权限 |
| 保存/取消 | 保存确认后落盘，取消放弃编辑 | 整理记忆后决定是否保留 | 沿用原有编辑器；新草稿停用，不把其冲突检测算当前能力 |
| 单篇分享 | 将记忆文件交给iOS系统分享 | 存“文件”、转给另一个AI | 原项目有单文件分享/文件浏览器导出组件；记忆页新按钮未接入 |
| 多选分享 | 选多篇用于项目交接 | 导出多天笔记 | ActivityView现成多URL分享可选用，但文件选择及合并内容未接入 |
| 外部变更检测 | 编辑时发生外部写入可提示冲突 | 避免旧草稿覆盖更新 | 独立草稿已退出编译，当前未引入此新增保护 |
| 明确错误提示 | 保存失败应显示错误 | 了解磁盘或权限异常 | 原有错误处理保留；新组权限和冲突错误界面未接入 |

当前入口仍是160650原有的设置→记忆和会话→记忆。此前设计的“查看、搜索与分享”新入口已退出接线；分组管理页和完整权限尚未实现。后续若接线，优先使用已审查的官方组件/开源组件，并标清必要适配。

**分享不等于共享权限**：把Markdown手动发给别人，不会自动让其他分组读取；不会默认上传到服务器，也不会把未选择的全局内容悄悄打包。导出文件可能包含隐私，分享前应查看。

本轮不增加自动删除、自动迁移或自动向全局回写。已有全局管理的删除/同步功能不等于新分组记忆已同步；分组备份和跨设备同步须另做作用域兼容，不能沿用仅全局的记录ID。
