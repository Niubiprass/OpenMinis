# MiniSight 交互规格（按参考视频逐帧还原）

参考：video_2E50BFE3（桌面）、video_BB94489B（会话列表）、video_C1669F40（设置）。
444×960 帧按 390pt 宽换算（×0.878）。以下是可验收的硬指标，不是示意。

## 两种元素，互不替代

| 元素 | 触发 | 位置 | 尺寸 | 消失 |
|---|---|---|---|---|
| 短气泡 | 点宠物 | 宠物头顶，间距 6pt，尾巴对准宠物 | 宽 ≤ 210pt，高随文字，最多 3 行后滚动 | 手动停留 2.5s / 点外部 / 发下一条 |
| 输入条 | 再点一次宠物（或点气泡） | 钉在 Dock 上沿上方 8pt，水平居中 | 宽 = 屏宽 − 20pt，高 30pt，圆角 15 | 发送后收起，气泡保留 |

关键：**输入条不跟宠物移动**。宠物走动、重力摇摆、键盘出现都不改变输入条的水平位置，只按键盘高度整体上移。

## 命中

- 输入条整条都是命中区（不是只有文本框）；左右各留 8pt 容错。
- 气泡命中区包含尾巴，点气泡 = 唤出输入条并聚焦。
- 输入条与气泡外全部穿透给桌面，不能整屏挡图标。
- 手指按住输入条时，布局暂停重排；松手才允许更新。
- 编辑窗只覆盖输入框本体，点外部立即收起键盘但输入条保留。

## 输入

1. 文字：点输入框 → 系统键盘；回车按设置执行发送或换行。
2. 语音：**不弹键盘**。按住麦克风 → 条内变成「正在听…」+ 波形 + 取消；松手转写进输入框；转写失败在原位提示并保留原文字；再点发送才发。
3. 语音识别走 App 的实时识别（SFSpeechRecognizer），插件只负责触发和显示；App 不在前台/未被唤起时，条内明确标“键盘听写”回退，不冒充语音直入。
4. 朗读开启时，条内显示「正在朗读」并可打断。

## 设置结构（原生 Settings 风格，分组分页）

主页面：启用、显示端、显示方式、预览、五个分类入口。
分类页：
- 手势与动作：允许互动、单击/双击/长按动作、自主活动、活动间隔、帧率、拖动响应、动作音效、倾斜强度、摇晃、大小、底部留白、重置位置。
- 配色与素材：素材导入/删除、配色、素材包列表、素材来源、深浅色。
- AI：地址、Key、模型、保存、测试、人设自动保存、用户称呼。
- 气泡与声音：气泡比例、文字比例、停留速度、回车、朗读、语音输入、打鼾。
- 主动互动与权限：主动开关、间隔、AI 总开关、12 个逐项“直接允许”、最近调整。
- 快捷按钮：开关、位置、排序、逐项短句、恢复默认。
- 录屏与诊断：录屏、长按录屏、日志开关、查看、导出、清理。

## 生效与验收

每个开关必须留下 `save→readback→publish→receive→apply` 五段，跳过必须带 reason。
装上一次即可用日志校验器逐项判 PASS/FAIL，不靠反复重建。

验收必须包含：不注销改开关立即生效；切两次显示端只留一只；锁屏隐藏、解锁恢复；键盘不改变输入条 x；点图标能穿透。
