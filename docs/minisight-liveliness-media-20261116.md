# MiniSight 0.8.43 本地候选：通用动作与歌词

本地基线：App `82f9fb1` / 已编译 build297；插件 `1e816aa` / 源码0.8.42。此前实装只读确认插件0.8.41。本批**未提交、未推送、未运行 CI、未安装、未注销/重启、未启动麦克风、未查询真实歌曲**。

## 用户批准的效果

- 不绑定大肥鱼；保留导入素材原件，把素材自带动作和通用受力反馈合起来。
- 拖动不再每次改方向就重播跑步第一帧；提起、轻晃/明显摇动、甩出、碰边、落地分别处理，文字和触摸区域不随角色转动。
- 气泡仅当前歌词，找不到同步词、暂停、未支持播放器或匹配不可靠则隐藏。聊天、审批和语音反馈优先。
- 在线补词自动以歌名、歌手、时长匹配 LRCLIB，不要求用户粘贴；不读取音乐账号或录音。独立开关默认关闭，开启时的联网内容在设置说明中明示。

## 素材与动作

新增原生 JSON 动作文件夹和单段 GIF 导入：保留原件、原始清单及海报，动作目录用不可复用UUID，当前/备份引用保护目录不被误删。旧静态/Petdex的 prepare/preview 保持原有实现。

- 单段 GIF（文件或直链）保留帧时长，作为待机片段。相册可能转换文件，保留动画优先从文件导入。
- 多动作选择根目录包含 `actions.json` 的本机文件夹；动作角色明确声明（idle、tap、drag、shakeSoft、shakeHard、flight、land、walkLeft、walkRight、jump、sleep、wake、idleAlt、music）。不按文件名猜语义，不自动猜任意图集。
- JSON文件路径为目录内相对路径，索引、时长、裁切、尺寸、文件大小与总量均有上限，符号链接/路径越界/重复字段拒绝；失败/取消不切换。
- 没有对应动作时使用待机/原画面与通用柔和反馈，不拿空中跑步冒充悬挂，不承诺图片会自动长出肢体、变为实时3D。
- 第一版不支持 ZIP、视频/WebM、远程 JSON 包、孤立JSON文件选择；APNG须在动作包中。

`MiniSightActionLibrary`后台有界解码，缓存8MiB/32帧上限；`MiniSightPetEffects`成功首帧才接管显示，取消/过时代次拒绝，坏帧有限重试后退回海报。短暂互动片段一次播放，收势完成再恢复；位置和旋转轴用阻尼连续处理，停下不突变。音乐目前是播放联动的平滑轻摆，**没有精准节拍检测**。

## 歌词与播放

插件为唯一系统播放观察/在线取词端。当前播放器目标为网易云、QQ音乐、酷狗、酷我、Apple Music；它们的最新版、iOS15.5和RootHide运行效果仍未逐个验证。存在可靠系统播放信息及在线匹配才可出词，不宣称读取各播放器原始歌词接口。

媒体回调取“信息→播放状态→信息”复核同一曲目，取消/超时/切歌代次隔离；只允许一条真实在途调用。亮屏不等于解锁，锁状态接口缺失/类型不符会关闭观察。系统时间戳是播放进度参考，不是回包时间，合法旧参考继续推算，越过曲尾则清空。

客户端为HTTPS固定端点、无cookies/凭据/磁盘缓存、拒绝重定向、有界响应、超时及负缓存/限流退避；仅使用严格匹配的带时间戳歌词。App内渲染读插件保存并核验的短快照，过期则清空；没有插件不能保证其他App歌词。
